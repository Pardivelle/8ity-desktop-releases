# 8ity para escritorio

Este repositorio **sólo aloja los instaladores** de la app de escritorio de
8ity. El código vive en un repositorio privado; aquí no hay fuentes.

Es público a propósito: el actualizador automático de la app lee el feed de
releases sin autenticarse, así que no hay ningún token embebido en el binario.

## Descargas

- **macOS** (Apple Silicon e Intel) —
  [8ity-macOS.dmg](https://github.com/Pardivelle/8ity-desktop-releases/releases/latest/download/8ity-macOS.dmg)
- **Windows** (10 y 11, x64) —
  [8ity-Windows.exe](https://github.com/Pardivelle/8ity-desktop-releases/releases/latest/download/8ity-Windows.exe)

Esos enlaces apuntan siempre a la última versión publicada.

## Actualizaciones

La app se actualiza sola: comprueba al abrir y cada 6 horas, y avisa cuando hay
una versión nueva lista para instalar.

El contenido del producto no depende de estas versiones — se sirve desde la web
y llega al escritorio en cuanto se despliega. Aquí sólo se publica el
contenedor: menús, atajos, pestañas y el propio actualizador.
